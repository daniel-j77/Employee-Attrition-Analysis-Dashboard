# Employee Attrition Analysis Dashboard

## Overview

Interactive dashboard built using Excel, SQL, Power BI, Python and Streamlit.

## Features

* Data Cleaning
* Employee Attrition Analysis
* Salary Analysis
* Promotion Analysis
* Department Performance
* Interactive Dashboard

## Tools

* Excel
* SQL
* Python
* Power BI
* Streamlit

## Dashboard Metrics

* Total Employees
* Average Salary
* Attrition Rate
* Promoted Employees

## Deployment

Streamlit App
