# Employee Attrition Analysis Dashboard

## Overview

Employee Attrition Analysis Dashboard is an end-to-end HR analytics project designed to analyze workforce retention, employee attrition trends, salary distribution, departmental performance, and promotion patterns.

The project integrates Excel, SQL, Power BI, Python, and Streamlit to perform data cleaning, transformation, exploratory data analysis (EDA), and dashboard development. It provides actionable insights into employee turnover, department-wise workforce distribution, salary variations, promotion statistics, and retention trends.

The dashboard helps organizations identify factors contributing to employee attrition, understand workforce dynamics, and support data-driven HR decision-making through interactive visualizations and KPI-driven reporting.

## Features

* Data Cleaning
* Employee Attrition Analysis
* Department-wise Workforce Analysis
* Salary Distribution Analysis
* Promotion Analysis
* Employee Retention Insights
* KPI Monitoring
* Interactive Dashboard
* Exploratory Data Analysis (EDA)

## Tools

* Excel
* SQL
* Python
* Power BI
* Streamlit

## Dashboard Metrics

* Total Employees
* Average Salary
* Attrition Rate
* Promoted Employees

## Business Insights

* The organization recorded an attrition rate of 33%, indicating opportunities to improve employee retention.
* IT department had the highest employee count among all departments.
* Finance department reported the highest average salary.
* A majority of employees remained with the organization, reflecting overall workforce stability.
* Promotion analysis highlighted a smaller proportion of promoted employees compared to non-promoted employees.
* Department-wise salary differences provided valuable insights into compensation trends across the organization.
